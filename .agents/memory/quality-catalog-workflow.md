---
name: Добавление заготовок для эталонов
description: Уточнённый пользователем способ ручного расширения каталога заготовок.
---

Пользователь уточнила прежний способ: «я добавляла их сама через запрос в бд прода».

**Why:** добавление заготовок в каталог для эталонов было ошибочно подготовлено через автодобавление при публикации; пользователь поправила этот подход.

**How to apply:** при аналогичном запросе проверить наличие позиций на проде и подготовить точечный SQL-запрос для пользователя, если доступ агента к продовой базе только для чтения. Не заменять этот процесс автодобавлением при запуске приложения без отдельной договорённости.
