---
name: Отложенная запись ID проработок
description: Согласованное пользователем поведение пустых ID в Google-таблице при просмотре и сохранении актов
---

Просмотр списка проработок не должен записывать ID в Google-таблицу. Для строк с пустым ID допустима временная привязка к физическому номеру строки; пустые ID заполняются при сохранении связанного акта. Уже существующие ID сохраняются.

**Why:** Пользователь подтвердил, что отложенная запись ID вместо автоматической записи при открытии списка в целом подходит. Простое чтение не должно иметь побочных эффектов в Google-таблице.

**How to apply:** Если меняется загрузка проработок или механизм привязки актов, не возвращать запись ID на обычный просмотр без нового согласования. Учитывать, что временная привязка пустой строки зависит от её позиции до сохранения акта.
