---
name: Позиции в списке ДХ
description: Ограничение списка ДХ: обычные производственные факты не должны попадать в него
---

В списке ДХ нужны только позиции ДХ.

**Why:** пользователь подтвердила: «нам нужны только позиции ДХ в этом списке». Обычные позиции с фактами ошибочно появлялись как числовые ID и считались полностью произведёнными сверх плана.

**How to apply:** наличие производственного факта само по себе не является признаком ДХ. Не включать на этом основании обычные позиции или неизвестные ID в список ДХ и не удалять их факты из цехов.
