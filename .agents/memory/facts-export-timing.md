---
name: Время выгрузки выполнения в ВХ
description: Требование пользователя о ночной выгрузке производственных фактов без изменения правил дат.
---

Данные по выполнению в ВХ должны записываться только в конце дня, исходя из факта. При изменении времени выгрузки не менять правила дат, переносов и накопления.

**Why:** пользователь указала, что данные, видимо, записываются постоянно, и попросила «сделай запись только в конце дня исходя из факта — правила по датам и тд не меняй».

**How to apply:** сохранять отметки в базе трекера сразу, но не запускать внешнюю выгрузку после каждого сохранения. Итоговую выгрузку строить по сохранённым фактам, используя прежнюю семантику плановых дат и переносов. Для надёжного ночного запуска учитывать, что Autoscale может останавливать приложение в отсутствие запросов.
